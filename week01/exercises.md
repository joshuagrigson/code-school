# Week 1 Exercises

Do these in order in `course/sandbox/`. Type everything by hand.

### 1. REPL warm-ups (10 min)
In the Python REPL, predict the result *before* pressing enter:
- `10 / 3` then `10 // 3` then `10 % 3` (division, floor division, remainder)
- `"na" * 4 + " batman"`
- `len("paper plate")`
- `type(3.0)` vs `type(3)`

### 2. `bio.py`
Ask for name, age, and favorite cuisine. Print one sentence using an f-string. Then print how old they'll be in 10 years (careful: `input()` gives strings).

### 3. `tip.py`
Ask for a bill amount and a tip percent. Print the tip and the total, e.g. `Bill $40.00 + tip $6.00 = $46.00`. Bonus: format to 2 decimals with `f"{total:.2f}"`.

### 4. `shout.py`
Ask for an ingredient. Print it uppercase, lowercase, its length, and inside the sentence `Add the ___ now!`.

### 5. Real-code scavenger hunt
Open `proxy/app.py` (just look, don't change anything). Find and write down in your journal:
- three variables holding strings
- one variable holding a number
- one f-string (search for `f"`)
- one comment

You won't understand most of the file yet. That's the point — by Week 4 you'll read all of it.

### Stretch goal
`servings.py`: ask how many servings a 2-serving recipe should make, and print the multiplier (e.g. 6 servings → "multiply every ingredient by 3.0").
